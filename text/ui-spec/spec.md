# 番茄TODO UI 规格（ui-spec）

> 来源：真机截图 1080×2400 px，**DPR = 3**，即逻辑画布 **360 × 800 dp**。
> 所有数值已换算为 **dp / sp**，可直接用于 Compose（`Dp`/`sp`）。
> 测量方式：像素扫描（原图 ÷ 3），误差 ±1dp。

---

## 1. 画布与全局

| 项 | 值 |
|---|---|
| 逻辑画布 | 360 × 800 dp |
| 状态栏高度 | **33 dp** |
| App 头部（含状态栏） | **90 dp**（内容区 57 dp） |
| 底部导航 | **52 dp**（图标 20 dp + 文字 10 sp） |
| 内容区可用高度 | 800 − 90 − 52 = **658 dp** |
| 系统字体 | 思源/系统默认中文（PingFang / MiSans） |

## 4. 组件尺寸

### 4.1 待办卡片

```
Card: 宽 340 dp（左右边距 10 dp）  高 68 dp  圆角 7 dp
  padding: 上 13  下 11  左/右 14
  布局: Row { Column[标题(顶) / 时长(底)] , “开始”(垂直居中，右) }
  间距: 卡片之间 6 dp，列表顶部距头部 9 dp
  装饰: 背景渐变 + 插画（右侧 55%~85% 区域，overflow 裁切）
```

### 4.2 待办集

```
列表头: 高 48 dp，白底，左侧 teal 竖条 4×26 dp（距左 0，右间距 10）
        标题 13 sp；右侧图标 4 个（下拉/饼图/齿轮/加号）17 dp，间距 12 dp
卡片:  高 53 dp  左右边距 4 dp  间距 5 dp  圆角 6 dp  padding 上9 下8 左右12
```

### 4.3 统计页卡片

```
白卡: 宽 342 dp（左右边距 9 dp） 圆角 12 dp  padding 上8 下9 左右9
      累计专注 / 当日专注 卡高 ≈ 75 dp
      卡间距 14 dp（含阴影视觉间距）
累计专注: 标题行 + Row 三等分（次数 / 时长 / 日均时长）
          大数字行 marginTop 5 dp，标签与数字间距 2 dp

      Canvas.drawArc，起点 −90°，顺时针

            英语阅读练习-翻译-作文 3.7% #D5E8E8 / 机械学习 2.8% #64919E / 锁机 0.8% #F2D489
      标签引线 stroke 1 dp `#90A4AE`，标签 11 sp `#546E7A`
图例: 两列 Grid，色点 8 dp，item 间距 10/8 dp
```

## 5. 每屏组件树（Compose 视角）

```
Scaffold(
  containerColor = 页面背景,
  topBar = { AppHeader }        // 90dp，含 33dp 状态栏留白
) { padding ->
    when (tab) {
      待办     -> TodoScreen        // LazyColumn<TaskCard>
      待办集   -> CollectionsScreen // 列表头 + LazyColumn<TaskCard>
      锁机     -> LockPlaceholder   // M4 再做
      统计数据 -> StatsScreen        // 4 张 StatCard，含 Canvas 饼图
      我的     -> MePlaceholder
    }
}
NavigationBar(height = 52dp) { 5 items }
```

`AppHeader` 结构（90 dp）：
```
Column {
  StatusBar(33dp)   // 时间 12.5sp + 右侧图标(蓝牙/静音/5G/电池/充电)
  Row(57dp) {
    Column { 标题 15sp ; 胶囊 10sp }   // 统计页无胶囊
    Row { 必开权限 ; 柱状图 ; 秒表 ; 加号 ; 更多 }  // 图标 20dp，间距 9dp
  }
}
```
